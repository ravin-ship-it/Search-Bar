# Search Bar Project

A simple and minimalistic search bar built using **HTML**, **CSS**, and **SCSS**. This project focuses on clean design and basic responsiveness for practice and learning.

---

## Features

- Minimal and clean UI
- Responsive layout for mobile devices
- Built with SCSS (compiled to CSS)
